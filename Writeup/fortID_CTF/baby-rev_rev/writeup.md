# Writeup: chall.pyc (Reverse, FortID)

**Категория:** Reverse **Формат флага:** `FortID{...}` **Файл:** `chall.pyc` **Флаг:** `FortID{nokia_3310_is_still_the_most_robust_piece_of_technology_i_have_ever_owned}`

## Условие

В задании дан только один файл, `chall.pyc`. Скрипт просит ввести флаг, и если он верный, печатает поздравление. Исходников нет.

## Первый взгляд

Первым делом я посмотрел, что это за файл:

```
$ file chall.pyc
chall.pyc: Byte-compiled Python module for CPython 3.10
```

Файл скомпилирован под Python 3.10, а у меня стоял 3.12, поэтому просто загрузить его через `marshal` и вызвать `dis` не получилось. Я поставил `xdis`, который умеет читать байткод разных версий Python:

```
pip install xdis uncompyle6 decompyle3
```

Декомпиляторы `uncompyle6` и `decompyle3` на 3.10 не сработали (`Unsupported Python version, 3.10`), поэтому я дизассемблировал байткод вручную через `xdis`.

Уже в константах модуля видно много интересного:

- `'FortID{'` и `'}'`: формат флага;
- `81`: длина флага;
- `'_'`: разделитель слов;
- `'33696-7383-3824-4-9465664238-36-32347-878267-8766-348-55487-74-0133-24566'`: подозрительная строка из цифр и дефисов;
- 64 hex-символа: sha256 флага;
- имена `t9text`, `get_touchtone`: пакет с T9-кодировкой.

## Разбор логики

По байткоду я восстановил исходник примерно так:

```python
import string
from hashlib import sha256
from t9text import t9

def nope():
    print("nope! ಠ_ಠ")
    exit(0)

user_input = input("pls text me the flag :P\n> ")

if len(user_input) != 81:
    nope()
if not (user_input.startswith("FortID{") and user_input.endswith("}")):
    nope()

words = user_input[len("FortID{"):-len("}")]
for w in words.split("_"):
    if not (all([c in string.ascii_lowercase for c in w]) or
            all([c in string.digits for c in w])):
        nope()

words = "-".join(words.split("_"))
if t9.get_touchtone(words)[::-1] != "33696-7383-3824-4-9465664238-36-32347-878267-8766-348-55487-74-0133-24566":
    nope()

if sha256(user_input.encode("utf-8")).hexdigest() != "3576c495f89236515fbbfbfb519dceb9899122e92460d418d2ce37a1ff357e0c":
    nope()

print("*\\0/* I knew you could do it! ^5")
```

Итого флаг должен удовлетворять четырём условиям:

1. Длина ровно 81 символ, формат `FortID{...}`.
2. Внутри скобок слова через `_`, и каждое слово состоит **либо только из строчных букв, либо только из цифр**.
3. T9-кодировка слов (через `-`), **развёрнутая задом наперёд**, равна заданной строке.
4. sha256 всего флага совпадает с хешем.

## Как работает T9 в `t9text`

Чтобы не гадать, я посмотрел исходник пакета `t9text` (он ставится из PyPI). Функция `get_touchtone` просто заменяет каждую букву на кнопку телефона, а цифры и `-` оставляет как есть:

| Кнопка | Буквы |
| --- | --- |
| 2 | abc |
| 3 | def |
| 4 | ghi |
| 5 | jkl |
| 6 | mno |
| 7 | pqrs |
| 8 | tuv |
| 9 | wxyz |

То есть кодирование не однозначное: одному коду соответствует много слов. Зато хеш в конце позволяет проверить, что я угадал верно.

## Ловушки

Я потерял на этом немало времени, пока не нашёл две вещи.

**1. Строка развёрнута.** В байткоде после `get_touchtone` стоит срез `[None:None:-1]`, то есть `[::-1]`. Я сначала искал слова под токены как есть, и ничего осмысленного не находилось (например, для `33696` и `9465664238` в словаре вообще не было кандидатов). После разворота получается:

```
66542-3310-47-78455-843-6678-762878-74323-63-8324665649-4-4283-3837-69633
```

Теперь токены идут в порядке слов флага, каждый тоже развёрнут обратно.

**2. Слова либо из букв, либо из цифр.** Сначала я думал, что в словах допустим leetspeak (`3` вместо `e`, `0` вместо `o` и т.п.), и написал перебор с leet-заменами. Это был тупик: оказалось, что слово не может смешивать буквы и цифры. Так что `3310` и `4` могут быть просто числами, а не зашифрованными буквами.

Суммарная длина тоже подтверждает логику: внутри `FortID{...}` ровно 73 символа, и в T9-строке тоже 73 символа (60 цифр + 13 дефисов).

## Решение

После разворота я подобрал слова по клавиатуре телефона:

| T9-токен | Слово |
| --- | --- |
| 66542 | nokia |
| 3310 | 3310 (цифры) |
| 47 | is |
| 78455 | still |
| 843 | the |
| 6678 | most |
| 762878 | robust |
| 74323 | piece |
| 63 | of |
| 8324665649 | technology |
| 4 | i |
| 4283 | have |
| 3837 | ever |
| 69633 | owned |

Получается фраза про Nokia 3310, самый знаменитый кирпич среди телефонов, что отлично сочетается с T9. Некоторые токены (`47`, `843`, `63`, `4`) допускают много вариантов, но осмысленная фраза и совпавший sha256 убирают неоднозначность.

**Флаг:** `FortID{nokia_3310_is_still_the_most_robust_piece_of_technology_i_have_ever_owned}`

## Скрипт решения

Чтобы не подбирать вручную, я написал скрипт: он разворачивает цель, для каждого токена собирает кандидатов (слова из словаря с таким T9-кодом плюс сами цифры) и перебирает комбинации, пока не совпадёт sha256.

```python
#!/usr/bin/env python3
import hashlib, itertools, os, re

TARGET = "33696-7383-3824-4-9465664238-36-32347-878267-8766-348-55487-74-0133-24566"
HASH = "3576c495f89236515fbbfbfb519dceb9899122e92460d418d2ce37a1ff357e0c"
PREFIX, SUFFIX, TOTAL_LEN = "FortID{", "}", 81

KEYPAD = {"2": "abc", "3": "def", "4": "ghi", "5": "jkl",
          "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"}
L2D = {c: d for d, ls in KEYPAD.items() for c in ls}

def t9(word):
    return "".join(L2D.get(c, c) for c in word)

def load_words():
    words = []
    try:
        from wordfreq import top_n_list
        words += top_n_list("en", 300000)
    except ImportError:
        pass
    for p in ("/usr/share/dict/words", "/usr/share/dict/american-english"):
        if os.path.exists(p):
            words += [w.strip().lower() for w in open(p, errors="ignore")]
    seen, out = set(), []
    for w in words:
        if re.fullmatch(r"[a-z]+", w) and w not in seen:
            seen.add(w); out.append(w)
    return out

def main():
    tokens = TARGET[::-1].split("-")      # ключевой момент: разворот
    by_code = {}
    for w in load_words():
        by_code.setdefault(t9(w), []).append(w)
    cands = [by_code.get(t, [])[:200] + [t] for t in tokens]  # слова + «слово из цифр»
    for combo in itertools.product(*cands):
        flag = PREFIX + "_".join(combo) + SUFFIX
        if len(flag) == TOTAL_LEN and hashlib.sha256(flag.encode()).hexdigest() == HASH:
            print("FLAG:", flag)
            return

main()
```

Скрипт работает быстро, потому что кандидаты отсортированы по частоте слов и нужные слова оказываются в начале списков.

## Выводы

- По магическому числу в начале `.pyc` определяется версия Python, и под неё нужен подходящий инструмент. Если декомпилятор не поддерживает версию, можно читать байткод через `xdis`.
- Всегда стоит внимательно смотреть на срезы в байткоде: `[::-1]` легко пропустить, а он полностью меняет задачу.
- Хеш в конце задачи нужен не для взлома, а для проверки: T9 неоднозначен, а sha256 однозначно подтверждает верную фразу.
- Если перебор не идёт, проверь свои предположения (у меня это был leetspeak) и перечитай условия проверок в коде.
