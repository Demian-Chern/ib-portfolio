# Zero Report — SOLAR CTF (реверс «аудитора» + алгебра по модулю)

Oct 17, 2026 · @Demian

## Условие

Reverse/misc-таск SOLAR. Сервис-«аудитор» принимает одну base64-программу на Python, прогоняет её через свой ограниченный интерпретатор и выдаёт «отчёт» из двух чисел `(a, b)`. По легенде автора: «если аудитор одобряет программу, её отчёт — все нули. Он прошёл все мои тесты. Докажи, что я неправ». Нужно добиться, чтобы программа была **принята**, и получить флаг.

Файлы: `service.py` (сам аудитор), `pack.py` (обёртка-шаблон программы), `glyphs.png`.

## Как устроен аудитор (`service.py`)

Программа оборачивается в канонический шаблон (`pack.py`) с функцией `generate()`, тело которой — единственное, что мы контролируем. Шаблон делает программу **квайн-подобной**: внутри доступна строка `SOURCE` — собственный исходник программы, и функция `H(SOURCE)`.

Интерпретатор у аудитора нарочно куцый — только `ast`-разбор `generate()`:

- разрешены присваивания имён и финальный `return [x, y]` ровно из двух элементов;
- из операций — `+ - * %`, унарный минус, целые литералы и единственный «магический» вызов `H(SOURCE)`;
- `H(SOURCE)` интерпретатор резолвит в константу `source_hash = sha256(source) mod P`, где `P = 2**127 - 1`.

То есть `generate()` вычисляет пару `(a, b)` из хэша собственного исходника.

### Условие приёмки

```python
accepted = ( 0 <= a < P and 0 <= b < P
             and (a != 0 or b != 0)
             and ((1 - h) * a + h * b) % P == 0 )   # h = sha256(source) mod P
```

Автор считал, что единственный способ удовлетворить линейное уравнение — это `a = b = 0` («all zeros»), но его же правило запрещает `(0,0)`. Кажется, что принять программу нельзя. Это и есть «подвох».

## Решение

Уравнение `(1 - h)·a + h·b ≡ 0 (mod P)` имеет ненулевые решения. Берём

```
a = h,  b = h - 1
```

Тогда `(1 - h)·h + h·(h - 1) = h - h² + h² - h = 0`. Условие `(a,b) ≠ (0,0)` выполнено (при `h ≠ 0`), оба в диапазоне `[0, P)`. Аудитор обязан принять.

Поскольку `H(SOURCE)` интерпретатор сам резолвит в нужный `h`, тело `generate()` тривиально:

```python
h = H(SOURCE)
return [h, h - 1]
```

## Эксплойт

[`solve.py`](./solve.py) собирает каноническую программу через `pack.pack(...)`, локально проверяет её тем же `service.audit(...)` и отправляет base64 на сервер:

```python
BODY = "h = H(SOURCE)\nreturn [h, h - 1]\n"
source  = pack.pack(BODY).encode()
payload = base64.b64encode(source).decode()
# python3 solve.py HOST PORT  -> сервер отвечает флагом
```

При приёме сервер возвращает содержимое переменной окружения `FLAG` — флаг `SOLARCTF{...}`.

## Итог

Задача маскирует простую алгебру под «реверс аудитора»: главное — прочитать ограниченный интерпретатор, понять, что `H(SOURCE)` даёт управляемую константу `h`, и решить линейное уравнение по модулю `P`. Пара `(h, h-1)` ломает инвариант «отчёт всегда нулевой», не нарушая запрет на `(0,0)`.
