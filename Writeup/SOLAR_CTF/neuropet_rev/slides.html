STAGE 1

Распаковка Android backup

Заголовок — 4 текстовые строки, третья говорит none: шифрования нет. Отрезаем заголовок и распаковываем zlib в .tar.

Отвлекающие манёвры

Пароль 0000 ничего не дешифрует. f/rList — сериализованный ArrayList с id ресурса btn_pill, к флагу не относится.

import zlib
d = open('neuropet.ab','rb').read()
i = 0
for _ in range(4):
    i = d.index(b'\n', i) + 1
open('backup.tar','wb').write(
    zlib.decompress(d[i:]))

# → apps/com.solarlabs.neuropet/a/base.apk

Формат .ab: ANDROID BACKUP, версия 1, флаг сжатия 1 (zlib), шифрование none. Внутри tar — стандартная раскладка adb-бэкапа, нам нужен base.apk.

STAGE 3

Скрытый dex в skin.dat

Гамма — LCG с константами glibc rand():

  • seed — первые 2 байта файла (LE)
  • state = state·1103515245 + 12345
  • ключ = (state » 16) & 0xff
  • первые 4 байта → магия dex\n

g = open('skin.dat','rb').read()
st = g[0] | (g[1] << 8)
out = bytearray()
for b in g[2:]:
    st = (st*1103515245 + 12345)
    st &= 0xffffffff
    out.append(((st>>16)&0xff) ^ b)
out[0:4] = b'dex\n'

Имя ассета neuro/skin.dat собирается в App.onCreate из массива, XOR с 43. Расшифрованный dex содержит пакет com.solarlabs.neuropet.lab.

Io io = Wire.link;  // = core.Q
io.run(de(53, {81,80,67,71,90,90,88}));  // "devroom"

Аргумент de(53, {...}) — XOR с 53, получается строка devroom. Лаборатория просит нативную VM выполнить функцию devroom и вернуть результат. Вся соль — в libneurocore.so.
