# gaslightCTF — no-info (crypto)

## Категория
Crypto

## Дано
Задание называется `no-info` — намеренно без каких-либо подсказок о
типе шифра. Приложен один файл `output.txt`:

```
Gxk ykotfr ykgd Hqkol tbqdoftr iol tdhzn usqll vozi lxkhkolt, ql
oy tcqhgkqzogf iqr zqatf hsqet viost it vqlf'z sggaofu. O hgxktr lgdt
dgkt voft qfr it ltzzstr wqea of iol eiqok, yqet zosztr xh zgvqkrl zit
lxf.

0w5exk1zn-41fz-f0z-l3exkozn
```

```
Author: william_etotheipi
```

Второй блок (`0w5exk1zn-41fz-f0z-l3exkozn`) внешне похож на UUID
(группы, разделённые дефисами), но не соответствует формату UUID
(8-4-4-4-12 символов) — очевидный намёк, что это тоже зашифрованный
текст, а не случайный идентификатор.

Никнейм автора `william_etotheipi` отсылает к тождеству Эйлера
`e^(iπ) = -1`. Проверка этой зацепки (сдвиги/операции с числами e и π)
ни к чему не привела — это красная селёдка (или просто пасхалка), а не
часть решения.

## Шаг 1 — Определяем тип шифра

Первая гипотеза для крипто-задания с текстом такого вида — шифр Цезаря
(простой сдвиг алфавита). Проверяем её на самом длинном слове —
`tcqhgkqzogf` (11 букв) — предполагая, что это может быть, например,
`explanation`.

Если бы это был Цезарь, разность между кодом буквы шифротекста и
буквы открытого текста должна быть **одинаковой для всех букв**.
Проверка:

```
t → e : разница 15
c → x : разница 5
```

Разница разная → гипотеза о едином сдвиге отвергается. Значит, это
**моноалфавитная замена** (substitution cipher): каждая буква шифра
всегда соответствует одной и той же букве открытого текста, но
соответствие — произвольная перестановка алфавита, а не сдвиг.

Такие шифры решаются не перебором, а классическим
**crossword-style** анализом: ищем структурные и частотные "зацепки",
из которых, как снежный ком, разворачивается весь алфавит.

## Шаг 2 — Ищем первые опорные точки

**Одиночная буква.** В тексте есть слово `O`, стоящее само по себе
(с большой буквы, отдельным словом, с точками до и после). В
английском языке практически единственное осмысленное слово из одной
буквы — это `I`. Значит:

```
O (шифр) → I (открытый текст)
```

**Слово с апострофом.** Слово `vqlf'z` имеет структуру
`XXXX'X` — 4 буквы, апостроф, 1 буква. Это классический паттерн
английской стяжки (contraction). Перебирая частые стяжки такого вида
(`wasn't`, `didn't`, `couldn't`...), по длине и структуре лучше всего
подходит **`wasn't`**:

```
v→w   q→a   l→s   f→n         z→t
w      a     s     n    '      t
```

Уже пять новых букв за один шаг.

## Шаг 3 — Раскручиваем алфавит через короткие слова

Имея `r→d` (из `qfr` → `a n d` = **and**), `i→h` (из `iqr` → `h a d`
= **had**), `o→i` (из `iol` → `h ? s`, и по частоте — `his`), `t→e`
(из `it` → `h e` = **he**), дальше каждая новая буква подтверждается
контекстом соседних слов — классический метод решения криптограмм
"вручную": частично расшифрованное слово почти всегда однозначно
достраивается до осмысленного английского слова, а это слово
достраивает алфавит дальше.

Цепочка новых слов, каждое из которых добавляет 1-2 буквы:

| Шифр | Открытый текст | Новые буквы |
|---|---|---|
| `ykotfr` | friend | y→f, k→r |
| `ykgd` | from | g→o, d→m |
| `Gxk` | Our | x→u |
| `Hqkol` | Paris | h→p |
| `hgxktr` | poured | (подтверждение) |
| `voft` | wine | (подтверждение) |
| `tdhzn` | empty | n→y |
| `usqll` | glass | u→g, s→l |
| `vozi` | with | (подтверждение) |
| `lxkhkolt` | surprise | (подтверждение) |
| `tcqhgkqzogf` | evaporation | c→v |
| `zqatf` | taken | a→k |
| `hsqet` | place | e→c |
| `tbqdoftr` | examined | b→x |
| `sggaofu` | looking | (подтверждение) |
| `wqea` | back | w→b |
| `eiqok` | chair | (подтверждение) |
| `zgvqkrl` | towards | (подтверждение) |

Все 22 встречающиеся в тексте буквы (буквы `j`, `m`, `p` в
ciphertext вообще не встречаются, поэтому их соответствие не нужно
для решения) сходятся без единого противоречия — верный признак,
что алфавит подобран правильно, а не подогнан.

## Итоговый алфавит замены (шифр → открытый текст)

```
a→k  b→x  c→v  d→m  e→c  f→n  g→o  h→p  i→h
k→r  l→s  n→y  o→i  q→a  r→d  s→l  t→e  u→g
v→w  w→b  x→u  y→f  z→t
```

## Шаг 4 — Расшифровка основного абзаца

Применяя таблицу ко всему тексту (скрипт на Python, буква за
буквой, с сохранением регистра и пунктуации):

```python
mapping = {
    'a':'k','b':'x','c':'v','d':'m','e':'c','f':'n','g':'o','h':'p','i':'h',
    'k':'r','l':'s','n':'y','o':'i','q':'a','r':'d','s':'l','t':'e','u':'g',
    'v':'w','w':'b','x':'u','y':'f','z':'t'
}

def decode(s):
    out = []
    for ch in s:
        if ch.isalpha():
            low = ch.lower()
            p = mapping.get(low, '?')
            out.append(p.upper() if ch.isupper() else p)
        else:
            out.append(ch)
    return ''.join(out)
```

Получаем связный английский текст:

```
Our friend from Paris examined his empty glass with surprise, as
if evaporation had taken place while he wasn't looking. I poured
some more wine and he settled back in his chair, face tilted up
towards the sun.
```

Это просто "затравочная" история — сам флаг в ней не спрятан,
проверено — никаких скрытых слов/акростихов в тексте нет.

## Шаг 5 — Расшифровка второй строки

Строка `0w5exk1zn-41fz-f0z-l3exkozn` состоит из цифр, дефисов и
букв. Ключевое наблюдение: **цифры в моноалфавитном шифре не
затрагиваются** — заменяются только буквы a-z, поэтому цифры остаются
на своих местах как есть, а буквы прогоняются через ту же самую
таблицу замены, что и основной текст:

```python
tail = "0w5exk1zn-41fz-f0z-l3exkozn"
print(decode(tail))
```

Результат:

```
0b5cur1ty-41nt-n0t-s3curity
```

Это классический **leetspeak** (замена букв на похожие цифры:
`o→0`, `i→1`, `s→5`, `a→4`, `e→3`). Раскодировав leet обратно в
буквы, получаем фразу:

```
obscurity - aint - not - security
```

То есть отсылка к известному тезису информационной безопасности
"*security through obscurity is not security*" (безопасность через
неясность — не безопасность), сформулированную разговорным двойным
отрицанием: **"obscurity ain't not security"**.

## Флаг

Поскольку исходная закодированная строка уже имела вид
`<группа>-<группа>-<группа>-<группа>` — тот же формат просто
оборачивается в `gaslightCTF{...}`, с сохранением дефисов и leet-цифр
один в один, как в оригинале:

```
gaslightCTF{0b5cur1ty-41nt-n0t-s3curity}
```

## Выводы / чеклист для похожих заданий

1. Если в тексте встречаются слова разной длины, знаки препинания и
   апострофы — это почти всегда **моноалфавитная замена**, а не
   Цезарь. Сдвиг проверяется за 10 секунд на любом длинном слове:
   если разность кодов не постоянна — сразу переключаться на
   crossword-подход.
2. Начинать взлом замены не с частотного анализа "в лоб", а с
   **структурных якорей**: одиночные буквы (`I`, `A`), слова с
   апострофом (стяжки типа `wasn't`, `don't`), короткие 2-3-буквенные
   слова (`the`, `and`, `he`, `of`) — они однозначно ограничивают
   набор кандидатов и запускают "снежный ком".
3. Каждую новую расшифрованную букву сразу проверять на
   непротиворечивость во всех остальных словах, где она встречается —
   любой конфликт (одна и та же буква шифра требует двух разных букв
   открытого текста) значит, что где-то раньше было выбрано неверное
   слово-гипотеза.
4. Если в "зашифрованном" фрагменте помимо букв встречаются цифры —
   проверить сначала, не является ли это **leetspeak** после
   расшифровки букв: цифры в substitution-шифре обычно не
   изменяются, только буквы.
5. Ник автора/название задания иногда — намеренный отвлекающий
   манёвр (red herring), а не часть криптографической схемы;
   не тратить время на попытки притянуть его к решению, если прямой
   структурный анализ уже даёт прогресс.
