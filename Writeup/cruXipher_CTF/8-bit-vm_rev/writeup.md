# cruXipher: 8-bit VM — врайтап

Oct 23, 2026 · @Demian

## Условие и флаг

Флаг: `cruXipher{4456e680}`.

Дана выдуманная 8-битная машина: три регистра R0, R1, R2 и 256 байт RAM (`0x00`–`0xff`). Перед стартом R0 = входной байт, R1 = R2 = 0, RAM обнулена. Программы — сырой байткод. Документации по системе команд нет, есть только пять примеров на четырёх программах с парами вход → выход (выход = R0 после остановки).

Задание: запустить `challenge.bin` со входом `0x2a`, после остановки прочитать `RAM[0x40..0x43]` и собрать флаг из этих четырёх байт в hex.

| Программа | Вход | Выход (R0) |
| --- | --- | --- |
| `kront.bin` | `2a` | `4a` |
| `vexx.bin` | `00` | `00` |
| `vexx.bin` | `01` | `c3` |
| `blip.bin` | `2a` | `7e` |
| `snok.bin` | `ff` | `55` |

## Система команд

Каждая команда — 2 байта: `XR AA`. Старший полубайт `X` — операция, младший `R` — регистр, второй байт — константа, адрес, смещение или регистр-источник.

| Опкод | Действие | Откуда взято |
| --- | --- | --- |
| `0r ii` | Rr = ii | `vexx`, `snok` |
| `1r 0s` | Rr = Rr + Rs (mod 256) | `kront`, `blip` |
| `2r ii` | Rr ^= ii | `kront`, `snok` |
| `3r 0s` | Rr = Rs | в примерах нет, подтверждено флагом |
| `4r oo` | если Rr == 0: PC = PC + 2 + (знаковое) oo | `vexx` |
| `5r aa` | RAM\[aa\] = Rr | все |
| `6r aa` | Rr = RAM\[aa\] | все |
| `70` | остановка | все |

Как выводились операции:

- **`vexx.bin`** (`01 c3 51 00 40 02 60 00 70`). R1 = c3, RAM\[0\] = R1. Далее `40 02`: при R0 = 0 перепрыгиваем `60 00` и получаем 00, иначе R0 = RAM\[0\] = c3. Отсюда `4r` = «переход, если Rr ноль», смещение считается от следующей команды.
- **`kront.bin`**. 2a + 7 = 31 даёт `10 01` = сложение регистров. Потом (2a ^ 33) + 31 = 19 + 31 = 4a — сходится, если `20 33` = XOR с константой.
- **`blip.bin`**. `11 01` удваивает R1 (2a → 54), затем 2a + 54 = 7e — подтверждает сложение.
- **`snok.bin`** (`50 0a 00 aa 50 0b 60 0a 20 aa 70 70`). Пишет вход в адрес `0x0a` — прямо поверх своего `70`, читает обратно и делает ff ^ aa = 55. Это первая подсказка: код лежит в той же RAM.

`3r` в примерах не встречается. По формату второго байта (`0s`, как у `1r`) это операция «регистр-регистр». Кандидаты mov / xor / or / sub / and дают разные флаги, принят вариант с mov.

## Где ловушка

Вся сложность задачи — в двух вещах, которые README не говорит прямо.

1. **Код и данные в одной RAM.** Программа грузится с адреса `0x00`, и фраза «RAM = all zeros» относится только к хвосту памяти. `challenge.bin` занимает `0x00`–`0x78`, так что ячейки `0x40`–`0x43`, из которых берётся флаг, — это сами команды. Программа сначала пишет туда `2a 2a 2a 40`, а потом исполняет эти байты как код. Ещё одна запись (`51 44`) превращает `21 4b` по адресу `0x44` в `49 4b`.
2. **Номер регистра берётся по модулю 3.** После самомодификации встречаются команды `2a ..` и `49 ..` с номером регистра 10 и 9. Если считать их неверными и останавливаться, получается ложный ответ `2a2a2a40`. Правильно — брать номер по модулю 3 (`0xa` → R1, `0x9` → R0) и идти дальше до настоящего `70`. Вариант «маска `& 3`» даёт тот же флаг.

Полезно и то, что пары `40 02 / 40 ea` и `40 02 / 40 ec` выглядят как циклы, но никогда не переходят назад. Обе команды проверяют R0 == 0, и если первая не сработала, вторая тоже не сработает. Так что программа идёт линейно и завершается за 60 шагов.

## Эмулятор

Эмулятор на Python воспроизводит все пять примеров и выдаёт флаг. Код грузится в общую RAM, номера регистров берутся по модулю 3.

```python
import sys

def run(path, inp):
    ram = bytearray(256)
    code = open(path, 'rb').read()
    ram[:len(code)] = code          # код живёт в той же RAM
    r = [inp, 0, 0]
    pc = 0
    while True:
        op, arg = ram[pc], ram[(pc + 1) & 0xff]
        hi = op >> 4
        d = (op & 0xf) % 3          # регистр-приёмник
        s = (arg & 0xf) % 3         # регистр-источник
        if hi >= 7:
            break                   # 70 = halt
        nxt = (pc + 2) & 0xff
        if   hi == 0: r[d] = arg
        elif hi == 1: r[d] = (r[d] + r[s]) & 0xff
        elif hi == 2: r[d] ^= arg
        elif hi == 3: r[d] = r[s]
        elif hi == 4:
            if r[d] == 0:
                nxt = (nxt + arg) & 0xff   # смещение знаковое за счёт mod 256
        elif hi == 5: ram[arg] = r[d]
        elif hi == 6: r[d] = ram[arg]
        pc = nxt
    return r, ram

r, ram = run(sys.argv[1], int(sys.argv[2], 16))
print('R0 =', hex(r[0]))
print('cruXipher{%s}' % ram[0x40:0x44].hex())
```

Запуск: `python3 vm.py challenge.bin 2a` → `cruXipher{4456e680}`.
